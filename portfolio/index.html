My First Program

The first line of code I ever wrote was a classic System.out.println("Hello, World!"); in Java. It was a small step, but it opened a huge door.

Below is the complete version of that first Java program:

public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Here is the same idea written in C++:

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
