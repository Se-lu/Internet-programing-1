# Selam Wagaye — Personal Portfolio Website

A three-page personal portfolio website built with plain HTML5 as part of the
AASTU Web Development laboratory assignment.

## Project Structure

```
portfolio/
├── index.html          # Home page
├── projects.html       # All projects page
├── thanks.html         # Form confirmation page
├── images/             # All image assets
├── audio/              # Audio introduction
├── videos/             # Project demo videos
└── files/              # CV PDF download
```

## How to Run

1. Open the `portfolio` folder in VS Code.
2. Right-click `index.html` and choose **Open with Live Server**, or
   double-click the file to open it directly in Chrome or Firefox.
3. No build step, server, or internet connection required for local viewing.

## Required Assets — You Must Supply These Files

Place each file in the correct folder before testing:

| File | Folder | Description |
|------|--------|-------------|
| `profile.jpg` | `images/` | Your profile photograph |
| `logo.png` | `images/` | Small logo showing your initials (SW) |
| `favicon.png` | `images/` | Browser tab icon |
| `connect-banner.png` | `images/` | Banner image with GitHub, LinkedIn, Email areas |
| `project-calculator.png` | `images/` | Screenshot of the calculator project |
| `project-library.png` | `images/` | Screenshot of the library project |
| `introduction.mp3` | `audio/` | Your recorded audio introduction |
| `calculator-demo.mp4` | `videos/` | Screen recording of the calculator |
| `library-demo.mp4` | `videos/` | Screen recording of the library system |
| `cv.pdf` | `files/` | Your CV in PDF format |

## Placeholders to Replace

Open `index.html` and replace these values:

- `YOUR_EMAIL` — your actual email address
- `YOUR_PHONE` — your phone number in international format, e.g. `+251912345678`
- `YOUR_GITHUB_USERNAME` — your GitHub username
- `YOUR_LINKEDIN_USERNAME` — your LinkedIn username
- YouTube embed URL in the "A talk I recommend" section
